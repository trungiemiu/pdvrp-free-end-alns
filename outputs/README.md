# Generated outputs

This directory is reserved for reproducible artifacts and is ignored by Git
except for this file.

- `experiments/` and `broader_experiments/`: per-instance, per-seed solver
  archives and quality metrics.
- `studies/`: ablation and sensitivity results.
- `validation/`: exact and independent feasibility checks.
- `paper/` and `broader_paper/`: publication-ready summary tables and figures.

Do not place maintained source code or manually edited manuscript content here.
Regenerate artifacts through `scripts/` or the root `pdvrp.ps1` entry point.
